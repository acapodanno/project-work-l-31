# Project Setup - HealthCare Plus

Questo repository contiene la struttura base per un progetto full-stack in ambito sanitario.

## Struttura

- `frontend/`: Contiene l'applicazione frontend in Angular 19.
- `backend/`: Contiene il servizio backend REST in Spring Boot 3 + Java 21.
- `docker-compose.yml`: avvio dei due container con `docker compose up --build`.
- `doc/`: relazione tecnica completa (screenshot in `doc/img/`).

## Documentazione e Avvio

*   [doc/README.md](./doc/README.md): relazione tecnica completa (9 capitoli — contesto, design UML/ER, API/Swagger, repository Git, processo di sviluppo, test funzionali, pianificazione delle fasi, risorse utilizzate, valutazione critica dei risultati), da considerarsi la relazione di riferimento richiesta dalla traccia.
