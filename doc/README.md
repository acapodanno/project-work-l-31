# Relazione Progetto: HealthCare Plus

Benvenuti nella documentazione ufficiale del progetto **HealthCare Plus**, la piattaforma per la gestione avanzata di una clinica polispecialistica supportata da Intelligenza Artificiale.

Questa directory contiene la relazione richiesta, suddivisa modularmente per facilitare la navigazione e la lettura.

   Scopri chi siamo, cosa offriamo e come si posiziona il nostro servizio AI.

   Modellazione dei dati (ER), Diagrammi di Sequenza (UML) e architettura di sistema (C4).

3. 🔌 **[Documentazione delle API (Swagger)](./3-API_Swagger.md)**
   Descrizione dei Controller RESTful e istruzioni per consultare l'interfaccia OpenAPI dinamica.

4. 📦 **[Repository Git e Struttura Codice](./4-Repository_Git.md)**
   Mappatura del Monorepo (Spring Boot + Angular) e procedure per la clonazione e l'avvio in locale.

5. 💻 **[Processo di Sviluppo e Code Snippets](./5-Processo_Sviluppo.md)**
   Resoconto delle logiche Agile, l'ottimizzazione dell'esperienza utente e spezzoni di codice backend e frontend di particolare interesse.

6. 🖼 **[Test Funzionali e Screenshot](./6-Test_Funzionali.md)**

7. 🗓 **[Pianificazione delle Fasi](./7-Pianificazione_Fasi.md)**

8. 🧰 **[Risorse Utilizzate](./8-Risorse_Utilizzate.md)**

9. 🔎 **[Valutazione dei Risultati](./9-Valutazione_Risultati.md)**
